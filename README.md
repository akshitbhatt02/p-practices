# Python Programming Practices

A collection of Python exercises, small scripts, and practice problems as I learn — covering fundamentals, problem-solving, and building toward more advanced projects.

## Purpose

This repo tracks my day-to-day Python learning journey. It's not meant to be a polished application — it's a working log of exercises, experiments, and concepts as I pick them up.

## Structure

`python-programming-practices/

├── data-structures/ # Lists, dicts, sets, tuples
├── exercises/ # CS50P and other course exercises
├── mini-projects/ # Small standalone scripts and tools
└── notes.md # Concepts and gotchas worth remembering`



## What I'm learning

- Python fundamentals (variables, control flow, functions, error handling)
- Working with data structures (lists, dictionaries, sets)
- File I/O and basic automation
- Problem-solving patterns from CS50P

Keeping practice code in one place — rather than scattered across random files — makes it easier to track progress over time and revisit old exercises when concepts need reinforcing.
